## Main-thread review

The source cache is owned by the same highlighter as the query cache, stores no mutable text copy and is keyed by source range plus canonical language. The mutation gateway clears it before text changes. It retains at most eight trees whose total source ranges are at most 1 MiB; tree allocation itself is grammar-dependent, so RSS is measured separately. Snippet parsers remain independent. No terminal dependency or public API changed.

One 512 KiB single Rust-fence public-pane probe measured 488.0 ms and 97.8 MB peak RSS in Normal, and 306.4 ms and 78.1 MB in source/Insert. This pathological size is recorded but is outside the approved 350 ms acceptance envelope. The accepted 128 KiB Rust-fence case measured about 142 ms in one release sample.
