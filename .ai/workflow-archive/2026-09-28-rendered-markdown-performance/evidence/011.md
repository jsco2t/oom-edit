## Main-thread review

The temporary borrow is constrained to the private builder lifetime and becomes owned text before publishing the layout. Exact mapped-fragment wrapping, table-cell provenance, parser-leaf borrowing, and existing full-build differential tests pass. The reload memory peak initially rose to 243.5 MiB because the old retained model overlapped replacement cache construction; releasing it within `LiveDocument::reload` reduced the final measured peak to 197.9 MiB without changing reload semantics. This was verified by the reload/model test, incremental suite, and full repository gate. Same-machine release measurements used Linux x86_64, AMD Ryzen 7 5700U, Rust 1.97.1; timings are host-sensitive, so both raw observations and structural tests are retained.
