## Main-thread review

The review added an exhaustive container/adjacent-block matrix and found a real boundary defect: inserting into a blank separator after a list, or deleting a newline adjoining a blank separator, can change the following paragraph even when the old block still reparses with the same kind and span. Local classification now widens those cases; focused regression tests pin both examples. Parser reference-expansion and Unicode case-folding cases retain the canonical full-parser fallback. The production renderer still rebuilds all width-dependent rows; that is task 010, not a claimed task-009 improvement.
